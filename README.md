# Java / AI 智能体开发面试练习 Skill

基于用户自行提供的《Java面试手册》，帮助同时准备 Java 开发与 AI 智能体开发岗位的学习者，练习**面试高频且基础**的问题。

## 学习方式

- 首批 10 道新题：通用基础 5、Java 专项 3、后端工程 2。
- 后续默认 6 道新题 + 4 道复习题；新题默认通用基础 3、Java 专项 2、后端工程 1。
- 每道新题同时符合“面试高频”和“基础”，答案和追问也保持基础难度；不随学习天数自动加入进阶源码或冷门参数题。
- 根据“会 / 模糊 / 不会”的反馈安排 1、3、7 天间隔复习。
- 用永久题号、批次号和本地持久记录去重、续学，未反馈不计作已掌握。

每题附范围、选题理由、PDF 来源页码、面试口述版答案、理解示例、常见追问和易错点。“高频”是定性选题依据，不代表统计排名或面试命中率。

## 安装与本地配置

将本仓库作为完整的 `java-ai-interview-practice` 文件夹放入本机的 skills 目录。保留 `SKILL.md` 与 `references/` 的相对位置。使用本地自定义 skills 目录时，以该客户端的实际配置为准。

首次使用时，向 agent 提供 PDF 的本地绝对路径，并指定需要沿用的学习记录目录。也可以在 skill 目录创建 `local-config.json`：

```json
{
  "source_pdf": "D:/your-materials/《Java面试手册》.pdf",
  "record_root": "D:/your-study-data/java-ai"
}
```

路径必须改为本机实际位置。已有学习记录优先沿用；本地配置与学习数据不提交到仓库。未指定记录目录时，默认使用当前用户主目录下的 `Documents/Codex/interview-practice/java-ai`。

## 使用示例

- “使用 $java-ai-interview-practice，开始今天的十题。”
- “B0001 的反馈：1会，2模糊，3不会。”
- “复习我的薄弱题。”
- “查看学习进度。”

默认同一天再次索要题目会返回已有批次；明确说“再来一组”才新增。跨天继续练习，漏学不自动补发所有日期。

## 题源与记录

`references/source-index.json` 保存原版 166 页 PDF 的 SHA-256 和目录书签，不包含 PDF 正文。使用者需自行提供该版本 PDF；更换版本先核对并重新索引，避免页码错配。网络、操作系统、算法和 Agent 专项的缺失内容须经用户授权后扩展题源。

学习记录规则见 [references/records.md](references/records.md)，完整执行规则见 [SKILL.md](SKILL.md)。skill 按用户请求执行；安装本身不会自动创建每日定时发送任务。
